# Geometry Dash object ID reference

Imported object ID/name data for the AI Decor project.

## Data source

- Upstream: https://github.com/FlowVix/gd-info-explorer
- Original data file: `src/lib/objects.csv`
- Imported from the upstream `main` branch on 2026-11-18.
- Upstream repository did not expose an explicit license file when checked. This import contains the ID/name reference data only; it does not include Geometry Dash sprite sheets, screenshots, or other game artwork. Review upstream terms before redistributing or using the dataset commercially.

## Files

- `data/object_ids.csv` — source-format ID/name pairs.
- `data/object_ids.json` — same entries as JSON objects with `id` and `name` fields.

The source list is a reference catalog and may not cover every object in every Geometry Dash version.
